## Hi there, I'm TD-Sky (`/thrē dĭ skī/`) 👋

I am a Linux software engineer, enjoy distilling best ***engineering*** practices from real-world problems.
When approaching an engineering problem, I prioritize identifying the most appropriate ***paradigm***.

My ***interests*** focus on addressing essential complexity:
- [Dependency injection](https://en.wikipedia.org/wiki/Dependency_injection)
- [Test harness](https://en.wikipedia.org/wiki/Test_harness)
- [Sans-I/O](https://sans-io.readthedocs.io/how-to-sans-io.html)
- System ***observability***, such as the design of error handling

Here are some ***projects*** embody the philosophy I favor:
- [kuDI](https://github.com/kudi-rs/kudi): Compile time interface-oriented dependency injection for Rust.
- [ratzgo](https://github.com/TD-Sky/ratzgo): Composable, async-first, elm-like TUI framework for Rust.

> I’m lazy when it comes to writing, so writing documentation for my projects always gets postponed :(

I’m always looking for ways to improve my ***workflow***.
Here's my personal configuration repository [***dotfiles***](https://github.com/TD-Sky/dotfiles) .
